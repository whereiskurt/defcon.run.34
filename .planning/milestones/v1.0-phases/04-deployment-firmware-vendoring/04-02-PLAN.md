**Create `infra/terraform/live/site/services/run.flash/service.hcl`** -- modeled on run.human/service.hcl but simplified (no DynamoDB tables, no uploads, no upload processors):

locals block containing:

1. **versions** -- read VERSION.app and VERSION.nginx from the service directory

2. **ecr_repositories** -- two repos:
   - `run-flash-nginx` in all 3 regions, IMMUTABLE tags, lifecycle: max 10 images, 30 day expire
   - `run-flash-app` in all 3 regions, IMMUTABLE tags, lifecycle: max 10 images, 30 day expire

3. **task** -- ECS task definition:
   - name: "run-flash", regions: all 3, cluster_name: "app"
   - task_cpu: 512, task_memory: 1024 (same as run.human, appropriate for lightweight Next.js)
   - Two containers:
     a) **run-flash-nginx** (256 CPU, 512 MiB, 256 reservation):
        - image: `run-flash-nginx:${local.versions.nginx}`
        - command: ["nginx", "-g", "daemon off;"]
        - readonly_root_filesystem: false
        - environment: APP_URL = "https://flash.{{SITE_DOMAIN}}"
        - port_mappings: 443
        - health_check: curl -k -f https://localhost/hello (interval 60, timeout 5, retries 3, start_period 120)
        - log_stream_prefix: "nginx"
     b) **run-flash-app** (256 CPU, 512 MiB, 256 reservation):
        - image: `run-flash-app:${local.versions.app}`
        - command: ["node", "server.js"]
        - readonly_root_filesystem: false
        - environment vars (same as run.human pattern, adapted for flash):
          NODE_ENV=production, HOSTNAME=0.0.0.0, REGION_SHORT={{REGION_LABEL}},
          AUTH_URL=https://flash.{{SITE_DOMAIN}}/{{REGION_LABEL}},
          NEXTAUTH_URL=https://flash.{{SITE_DOMAIN}}/{{REGION_LABEL}},
          AWS_REGION={{REGION}}, AUTH_COOKIE_DOMAIN=.{{SITE_DOMAIN}},
          SITE_DOMAIN={{SITE_DOMAIN}},
          AUTH_PUBLIC_URL=https://auth.{{SITE_DOMAIN}}/{{REGION_LABEL}},
          AUTH_INTERNAL_URL=http://run-auth.app-{{REGION_LABEL}}-{{SITE_DOMAIN_SLUG}}.local:3000/{{REGION_LABEL}},
          FLASH_PUBLIC_URL=https://flash.{{SITE_DOMAIN}}/{{REGION_LABEL}},
          RUN_DYNAMODB_REGION={{REGION}}
        - secrets (SSM Parameter Store paths):
          AUTH_JWT_SECRET from /{{SITE_LABEL}}/secrets/{{REGION_LABEL}}/jwt/secret,
          OIDC_CLIENT_ID from /{{SITE_LABEL}}/secrets/{{REGION_LABEL}}/flash/client_id,
          OIDC_CLIENT_SECRET from /{{SITE_LABEL}}/secrets/{{REGION_LABEL}}/flash/client_secret,
          AUTH_INTERNAL_SECRET from /{{SITE_LABEL}}/secrets/{{REGION_LABEL}}/jwt/internal_secret,
          RUN_ELECTRO_ID from /{{SITE_LABEL}}/dynamodb/{{REGION_LABEL}}/run-human-electro/access_key_id,
          RUN_ELECTRO_SECRET from /{{SITE_LABEL}}/dynamodb/{{REGION_LABEL}}/run-human-electro/secret_access_key,
          RUN_ELECTRO_DBNAME from /{{SITE_LABEL}}/dynamodb/{{REGION_LABEL}}/run-human-electro/table_name
        - port_mappings: 3000
        - health_check: curl -f http://localhost:3000/{{REGION_LABEL}}/ (interval 30, timeout 5, retries 3, start_period 120)
        - log_stream_prefix: "app"

4. **service** -- ECS service definition:
   - name: "run-flash", regions: all 3, cluster_name: "app", task_family: "run-flash"
   - desired_count: 1 (booth tool, limited concurrent users)
   - service_discovery: name "run-flash", container_name "run-flash-app"
   - load_balancers: ALB on run-flash-nginx:443, HTTPS target group, /hello health check
   - listener: port 443, HTTPS, host_headers: ["flash.{{SITE_DOMAIN}}"]
   - autoscaling: enabled=false, min=1, max=2 (can bump manually if needed)

Note: NO dynamodb block in flash service.hcl -- flash reads from run-human-electro table (not its own table). DynamoDB credentials are passed via SSM secrets referencing run-human-electro.
