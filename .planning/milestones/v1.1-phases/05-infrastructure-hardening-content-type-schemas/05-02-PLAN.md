**Step A: Create the shared coordinates component**

Create directory `apps/run.cms/app/src/components/shared/` and write `coordinates.json`:

IMPORTANT: This is a Strapi component file (single JSON file), NOT a content type (which would be `content-types/{name}/schema.json`). Components live at `src/components/{category}/{name}.json`.

```json
{
  "collectionName": "components_shared_coordinates",
  "info": {
    "displayName": "Coordinates",
    "description": "GPS latitude/longitude pair",
    "icon": "map-pin"
  },
  "attributes": {
    "latitude": {
      "type": "decimal",
      "required": true,
      "min": -90,
      "max": 90
    },
    "longitude": {
      "type": "decimal",
      "required": true,
      "min": -180,
      "max": 180
    }
  }
}
```
