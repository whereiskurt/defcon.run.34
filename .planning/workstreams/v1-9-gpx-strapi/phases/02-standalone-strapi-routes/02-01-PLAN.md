<objective>
Open the CMS authoring surface for standalone Strapi routes: add the free-text
`Route.mapFolder` field (default "DEF CON 34 Maps") that decides which public-map group a
standalone route folds into (design decision D3 / detailed design §1), and verify Strapi
actually accepts a `.gpx` upload into the existing `Route.gpxFiles` media field (Risk 2),
whitelisting the extension/mime in `config/plugins.ts` only if the uploader rejects it.

This is the CMS-side half of Phase 2 and is file-disjoint from the run.gpx code (plans 02-02 /
02-03), so it runs in parallel (wave 1). It creates NO new content-type and does NOT touch the
`point-of-interest` schema (POIs land in Phase 3).

Purpose: Give curators the one new field they need to place a route, and confirm the GPX asset
they attach will actually upload.
Output: One new schema attribute (`mapFolder`); `config/plugins.ts` edited only if the .gpx
upload verification requires a whitelist. No build/deploy (release is separate).
</objective>
