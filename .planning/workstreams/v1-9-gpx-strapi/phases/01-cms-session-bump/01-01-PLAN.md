<objective>
Raise the Strapi CMS admin session lifespan from 600s (~10 min) to 7200s (2h) so editors
(Jesse & co.) stay logged in for a realistic authoring session instead of being bounced to
OIDC every ~10 minutes. Implements decision D9 from the approved design contract.

Change exactly two `env.int` default literals in `apps/run.cms/app/config/admin.ts`
(`maxRefreshTokenLifespan` and `idleRefreshTokenLifespan`) from `600` to `7200`, keep the
5-minute access token (`ADMIN_ACCESS_TOKEN_LIFESPAN`, default 300) UNCHANGED, and confirm no
infra env pins the old values (which would make the code default inert). Tradeoff accepted per
D9: CMS access-revocation latency grows to ~2h for the small trusted editor pool.

Purpose: Operational convenience for the trusted CMS editor pool ahead of the Strapi-authored
routes/POIs work; independent, smallest, shippable alone.
Output: One edited config file. No new symbols, files, or schema. No build/deploy (release is
separate).
</objective>
