# Sketch 002: Badge Slots

## Design Question
Discrete achievements — the bib-purchaser starter badge and unique-connect
milestone pins — need a home around the QR. Where do they dock so they read as
earned hardware without crowding the scan zone?

## How to View
open .planning/sketches/002-badge-slots/index.html

Toggle "BIB PURCHASER" to see the starter badge appear/disappear.
Hover badges for lore tooltips; click to pop. Runner shown at L3 / 41 connects.

## Variants
- **A: Pin Rail** — earned badges line up on a pill rail under the QR; locked slots show dashed placeholders (what's next).
- **B: Corner Chips** — badges dock around the card corners at jaunty angles, like pins on a jacket.
- **C: Clearance Column** — a vertical rank ladder beside the QR, insignia-style, with names.

## What to Look For
- Does the bib-buyer badge (amber) read as "special/purchased" vs earned (magenta/green)?
- Do locked placeholders motivate, or clutter?
- Which layout survives a phone-width screen (use the toolbar viewport buttons)?
- B risks visual collision with sketch 001's corner brackets — if both win, they must compose.
