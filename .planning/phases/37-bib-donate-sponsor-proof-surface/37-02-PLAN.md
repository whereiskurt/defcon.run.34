|----------|-------------|
| editor/CMS → server render | ui-string values (editor-controlled) are resolved server-side and rendered as React nodes |
| server → client | Only resolved strings/nodes reach the browser; the loadCopy resolver + CMS token never cross |

| T-37-02b | Information Disclosure | server pages importing @/lib/copy | high | mitigate | @/lib/copy is imported ONLY by server components/pages (already server-only by contract); no client component imports it; only resolved strings pass to presentational children |
| T-37-02c | Tampering | overlong/garbage editor copy | low | accept | Copy is text-only; layout tolerates arbitrary strings; malformed content degrades gracefully to the snapshot floor via loadCopy |
