<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → client | CopyProvider carries only the resolved copy map into the browser; the CMS token/URL never cross |
| editor/CMS → client render | ui-string values (editor-controlled) render inside client components via useCopy |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-03a | Information Disclosure | SponsorForm/RunnerCodeBadge imports | high | mitigate | Client components import only useCopy (CopyProvider) + copy-core; they MUST NOT import @/lib/copy (server resolver) — grep-gated in verification |
| T-37-03b | Injection (XSS) | interpolated CTA/error/note | high | mitigate | Copy renders as React text children (auto-escaped); amount/detail pass as vars into t(), never concatenated into markup; no raw-HTML injection prop used |
| T-37-03c | Tampering | editor-supplied labels | low | accept | Text-only labels; malformed values degrade to the snapshot floor via useCopy |
</threat_model>
