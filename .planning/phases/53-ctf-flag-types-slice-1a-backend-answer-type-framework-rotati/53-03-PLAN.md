<objective>
Extend `judgeSolve` and its `CtfStore` seam with the flag-types gates: an unlock/chaining gate, answer-type
dispatch (static hash vs otp verify), and the repeatable-scoring path that writes the `CtfScoreEvent` ledger
with atomic once-per-window / per-player-max / global-max enforcement. Static one-award flags keep their
existing `CtfSolve` path byte-for-byte. Every gate failure is an indistinguishable non-solve.

Purpose: This is the heart of the framework — it turns the shipped single-static judge into a multi-answer,
repeatable, chained scorer while preserving the LOCKED never-throw / claim-before-allocate / indistinguishable-
failure invariants that keep the covert channel invisible and scoring race-free.

Output: Extended `JudgeCtf`/`narrowCtf`/`CtfStore`/`defaultStore` and `judgeSolve` ordered-gate flow, plus a
new gate test suite proving unlock indistinguishability, otp dispatch, atomic once-per-window concurrency,
perPlayerMax, globalMax, and CtfScoreEvent -> RunUser accrual.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| player solve -> judgeSolve | untrusted guess + identity-trusted user cross into the scoring gates |
| judge -> CtfScoreEvent | the atomic once-per-window claim is written from the hot solve path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-53-03-01 | Elevation | double-award via concurrent same-code submit | high | mitigate | conditional put on CtfScoreEvent (user#<bucket>) BEFORE allocateOrdinal — atomic, no read-then-write |
| T-53-03-02 | Information disclosure | unlock/rate-limit gate reveals a solve oracle | high | mitigate | every gate failure returns the identical NON_SOLVE shape; covert win gate stays points>0 only |
| T-53-03-03 | Elevation | globalMax bypass via racy partition count | medium | mitigate | globalMax uses the atomic allocateOrdinal ordinal (n>globalMax => award 0), never a partition query |
| T-53-03-04 | Spoofing | OTP replay for repeated points | medium | mitigate | verifyTotp + perPlayerIntervalHours cadence bound replays to one award per window |
| T-53-03-05 | Information disclosure | guess/secret leak in logs | high | mitigate | reuse ctfJudgeLog (no value field); never log guess or otp.secret |
</threat_model>
