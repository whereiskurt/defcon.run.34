<objective>
Wire the reward `effect` through the judge onto the NON-COVERT solve response only: load `effect` in
`narrowCtf`, add it to `JudgeResult`, return it from `judgeSolve`, and recognize the new
`{kind:"otp-enroll", otpauth, nextFlag?}` shape as a carried payload (the renderer is Slice 1b). Prove
the covert CSS path stays byte-identical and never carries a reward payload.

Purpose: `Ctf.effect` is authored and stored today but never read on the solve path — the `otp-enroll`
reward is net-new plumbing. It must reach the visible claim response yet stay entirely out of the covert
channel so the covert win/wrong/unauth responses remain indistinguishable.

Output: `effect` on `JudgeCtf`/`narrowCtf`/`JudgeResult`/`judgeSolve`, an `OtpEnrollEffect` type, and
tests proving non-covert surfacing + covert byte-identical invariance.
</objective>
