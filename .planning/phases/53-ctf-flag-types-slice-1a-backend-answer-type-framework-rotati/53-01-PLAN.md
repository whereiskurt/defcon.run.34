<objective>
Lay the additive data-model + pure-helper foundation for the flag-types framework: extend the `Ctf`
entity with all new optional gating fields, add the `CtfScoreEvent` append-only ledger entity, and
create the pure flag-type helper module (`isRepeatable`, `scoreBucket`, `assertAnswerTypeTransition`)
plus the edit-semantics guard. Everything is additive and backward-compatible — a shipped row with no
`answerType` reads and scores exactly as a static flag does today.

Purpose: Every later plan (TOTP core is independent; judge gates + effect plumbing depend on this)
needs the entity fields and the pure routing/guard helpers to exist first. This plan owns the entity
layer and the pure seams so the judge plan (53-03) never has to touch entities.

Output: New `Ctf` fields, the `CtfScoreEvent` entity + item type + key-parity lock, the
`ctf-flag-types.ts` pure module + its unit tests, and the CTFT-06 write guard wired into `upsertCtf`.
</objective>
