<objective>
Wire the existing check-in write path to the new Accomplishment entity: extend
`createCheckIn()` in `entities/checkin.ts` to also create the matching `activity`
accomplishment (carrying the check-in's `isPrivate` and `checkInId`), and
`deleteCheckIn()` to delete it — both idempotently. Implements LDBR-04.

Purpose: this is the one live producer of accomplishments in Phase 49 (GPX arrives
in Phase 50). It makes SC #1 real end to end: a check-in now raises the runner's
`activityScore`/`activityCounts.checkin`, and deleting it reverses that.
Output: extended `checkin.ts` + an idempotency unit test.
