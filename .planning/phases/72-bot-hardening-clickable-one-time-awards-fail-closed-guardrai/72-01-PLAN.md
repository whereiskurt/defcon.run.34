<objective>
Add the reserved `/a/<nonce>` award namespace to the q.defcon.run resolver Lambda so
every mesh bot award becomes a 35-character tappable link
(`https://q.defcon.run/a/k7m3q9x2wr4t`) instead of the current 79-character
`run.defcon.run/use1/ctf/claim?nonce=<uuid>`.

Per D-"Reserved letter is `a`": `/c/` was REJECTED — `q.defcon.run/c` is a LIVE short
code resolving to `didhtp1`. Letters `b c d f g h p r` are all taken.

Purpose: shorten and harden the award link surface, and make the namespace
un-shadowable by any operator-minted `Qr` code.
Output: a fifth `ParseResult` kind, a `buildClaimHandoff` response builder, the
`resolve` wiring, and unit coverage including the shadowing regression guard.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet -> CloudFront -> ALB -> resolver Lambda | Fully untrusted path segments arrive here from QR scans and forwarded links |
| resolver -> run.defcon.run claim page | The resolver forwards, never scores; run.human owns all award decisions |
| resolver -> CloudWatch Logs | Anything logged is retained and readable by anyone with log access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-72-01 | Spoofing | `parse-path.mjs` award branch | high | mitigate | Reserved-namespace check runs before the redirect classification, so no operator-minted `Qr` code can shadow `/a/`; asserted by a parse-path test |
| T-72-02 | Tampering | `respond.mjs` `buildClaimHandoff` | medium | mitigate | `encodeURIComponent` on the nonce prevents query-parameter injection into the claim URL; asserted by a metacharacter test |
| T-72-03 | Information disclosure | `resolve.mjs` award branch | high | mitigate | The branch emits no log line at all; asserted by a zero-length captured-log test |
| T-72-04 | Denial of service | award branch latency/throttle | medium | mitigate | Pure lexical rewrite with no DynamoDB read; asserted by `getQr` never-called test |
| T-72-05 | Elevation of privilege | award link forwarding | medium | transfer | Single-use enforcement lives in run.human `claimPending` (delete) backstopped by `judgeSolve`'s conditional-put `CtfSolve`; the resolver deliberately holds no authority |
| T-72-06 | Repudiation | award scans unlogged | low | accept | Deliberate: award redemption is recorded as a `CtfSolve` row in run.human, which is the authoritative audit trail. Scan-level analytics are sacrificed to keep the nonce out of CloudWatch |
</threat_model>
