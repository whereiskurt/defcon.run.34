<interface_context>
Verified 2026-07-31. Deploy is ALWAYS GitHub Actions (AGENTS.md Essential Rule 4) —
never a local `terragrunt apply`, never `release-all.sh --with-terragrunt`.

- `buildpub.yml` is the preferred release path and AUTO-MERGES the Release PR
  (`create_pr` defaults true). Its `deploy` input defaults FALSE on purpose: buildpub's
  inline deploy reads main's VERSION while the bump lives in the as-yet-unmerged Release
  PR, so it would deploy the PREVIOUS image. Leave it false and ship via `deploy.yml`.
- `apps` accepts a comma-separated list; `regions` is a choice — use `use1`. cac1 is in
  `site.skip_regions` and is explicitly OUT of scope for this phase.
- The local `apps/build.sh meshtk` path is KNOWN-BROKEN. Release run.mqtt via
  `buildpub.yml` only.
- ECR repos are IMMUTABLE. A build fails loudly if the tag already exists, so the Release
  PR's VERSION bump must produce a NEW tag. Never pass `skip_bump` onto an
  already-released version. An aborted release leaves orphan ECR tags and, worse, VERSION
  bumps with no built image — which makes a later ECS pull fail.
- `deploy.yml` inputs: `region`, `pr_number` (a number, or `latest`, or `skip` to deploy
  without merging), `invalidate_cache`. It applies ONLY `modules: ecs-task,ecs-service`
  (deploy.yml line 129) — the admin-reports alarm needs its own apply.
- `terragrunt-apply.yml -f region=us-east-1 -f modules=admin-reports` for the alarm.
  Never leave `modules` empty.
- WORKTREE LANDMINE: `build.sh` reads `TF_VAR_profile_prefix` from the repo-root
  `env.local.sh`, which is gitignored and therefore absent in a fresh worktree. Without
  it the AWS profile silently collapses and the build dies at the post-build S3
  static-asset sync with exit 255 AFTER the images already built. The phase context
  records this file as already copied — RE-VERIFY it exists at the worktree root before
  releasing.
- ECS does a rolling replace (old task drains while the new one health-checks), so CI
  going green is NOT proof the new task is serving.
- run.human live version probe: `curl -s https://run.defcon.run/use1/ | grep -oE 'v0\.0\.[0-9]+'`.
- An authed `/admin/*` route returns 404 to UNAUTHENTICATED probes by design
  (non-disclosure gate) — a 404 from curl is NOT evidence a route is missing.
</interface_context>
