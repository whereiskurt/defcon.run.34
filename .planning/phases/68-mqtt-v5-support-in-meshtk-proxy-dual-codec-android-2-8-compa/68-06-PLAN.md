<objective>
Close three of the four SC3 parity defects that live in one place: `handleProxyV5`'s
non-PUBLISH relay branch, which today special-cases PUBLISH and relays everything else as
captured bytes with no tracking, no authentication and no rules.

- **CR-02** — the 3.1.1 loop refreshes `ConnTrack` on every packet type; the v5 loop only ever
  reaches `SetConnTrack` through `inspectV5Publish`. The reaper purges any entry idle >180s, so a
  v5 session on the normal Meshtastic cadence (position ~15 min) loses its entry while its
  keepalives sail past untracked, and its next publish is Blocked with "Username required for
  MQTT" and the socket is torn down. Reproduced by the verifier as PROBE-B. This is the defect
  that silently degrades every live Android session.
- **CR-03** — because only PUBLISH is special-cased, a second CONNECT is forwarded to mosquitto
  carrying the client's own plaintext username and password, and AUTH is relayed too, both
  contradicting invariants this phase asserts.
- **WR-04** — v5 SUBSCRIBE never reaches `PacketDecider` and `MQTT.Topics` is never recorded, so
  topic rules apply to 3.1.1 clients only.

Purpose: SC3 ("every proxy security/inspection feature works identically on v5"), the parts
carried by MQV5-02 (per-type v5 handling), MQV5-03 (client creds never reach mosquitto) and
MQV5-05 (wire-level regression tests).
Output: `touchConnTrack` in inspect.go; `writeMqtt5Disconnect` + an explicit frame switch in
proxy_v5.go; `inspectV5Subscribe` in inspect_v5.go; a codec-independent `AllowMQTTControl` in
rules.go; one new wire-level test file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| v5 client -> proxy control frames | Attacker-chosen frame types and contents on an already-authenticated socket |
| proxy -> mosquitto | The socket across which the swapped `proxy` identity — and nothing of the client's — may travel |
| ConnTrack map -> rules engine | `Track.Username` is the identity every Block rule keys on; an absent entry means an empty username |
