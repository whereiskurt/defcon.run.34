<objective>
Give the meshtk proxy a per-connection MQTT v5 codec seam: pin the v5 wire codec, add a
version-independent frame reader, dispatch protocol-level-5 connections into dedicated v5
read loops, and implement full v5 CONNECT/CONNACK parity (credential verify, credential
swap, version-correct reject reason codes, topic-alias suppression in both directions).
Everything that is not CONNECT or CONNACK is relayed as captured raw bytes in this plan;
v5 PUBLISH inspection lands in plan 68-02 and is deliberately fail-closed here.

The 3.1.1 code path must come out of this plan byte-for-byte unchanged in behavior — that
is a hard requirement from CONTEXT ("Stability is a HARD requirement", Kurt verbatim), and
it is proved by a golden fixture generated from the pre-change code before any edit.

Purpose: MQV5-01 (per-connection version dispatch), MQV5-03 (v5 CONNECT auth), and the
framing half of MQV5-02 (raw relay of unhandled types), with the MQV5-05 tests that cover them.
Output: paho.golang v0.22.0 pinned + vendored; proxy_v5.go; inspect_v5.go; two new test
files; additive-only edits to proxy.go, inspect.go and rules.go.
</objective>
