Create the `run.bib` Terragrunt service definition and wire it into `site.hcl`, modeled directly on `run.flash`.

Purpose: bib.defcon.run needs the same infrastructure surface as flash.defcon.run — two ECR repos, a two-container ECS task, an ALB load balancer, service discovery, a subdomain (for ACM + CloudFront + Route53), and registration in the site-level services map. This plan produces the service definition and subdomain wiring; SSM secrets and CloudFront/ACM verification are 19-02.

Output: `services/run.bib/service.hcl` (+ VERSION files) and `site.hcl` updated so the new service is discovered by the ECR, CloudFront, ACM, and ECS modules, with zero drift for existing services.
</objective>

  <name>Task 1: Create services/run.bib/service.hcl from the run.flash template</name>
  <files>infra/terraform/live/site/services/run.bib/service.hcl, infra/terraform/live/site/services/run.bib/VERSION.app, infra/terraform/live/site/services/run.bib/VERSION.nginx</files>
  <action>
Copy `infra/terraform/live/site/services/run.flash/service.hcl` to `infra/terraform/live/site/services/run.bib/service.hcl`, then apply these substitutions throughout:

1. **Names:** `run-flash` → `run-bib`, `run-flash-nginx` → `run-bib-nginx`, `run-flash-app` → `run-bib-app`. This covers `ecr_repositories[].name`, `task.name`, every `containers[].name`, `containers[].image`, `service.name`, `service.task_family`, `service.service_discovery.*`, `load_balancers[].container_name`, and `log_stream_prefix` values.
2. **Domain / host headers:** every `flash.{{SITE_DOMAIN}}` → `bib.{{SITE_DOMAIN}}` (APP_URL, host_headers, listener host_headers).
3. **Auth env follows the run.gpx pattern, NOT flash** (bib uses the gpx Auth.js wiring — see 20-CONTEXT). Specifically, take the auth-related env block from `services/run.gpx/service.hcl` and adapt it for bib:
   - `AUTH_URL` and `NEXTAUTH_URL` = `https://bib.{{SITE_DOMAIN}}/{{REGION_LABEL}}/api/auth` (full path **including `/api/auth`** — gpx form, not flash's bare URL)
   - Add `AUTH_SERVICE_URL`, `AUTH_PUBLIC_URL` = `https://auth.{{SITE_DOMAIN}}/{{REGION_LABEL}}`, and `AUTH_INTERNAL_URL` = `http://run-auth.app-{{REGION_LABEL}}-{{SITE_LABEL}}.local:3000/{{REGION_LABEL}}` exactly as gpx defines them
   - `BIB_PUBLIC_URL` = `https://bib.{{SITE_DOMAIN}}/{{REGION_LABEL}}` (parallels gpx's `GPX_PUBLIC_URL`; the webapp uses it to build `redirectProxyUrl`)
   - Keep `AUTH_JWT_SECRET` and `AUTH_INTERNAL_SECRET` secrets (gpx has both)
4. **Secrets paths:** `/{{SITE_LABEL}}/secrets/{{REGION_LABEL}}/flash/client_id` → `.../bib/client_id` and same for `client_secret`. Keep `jwt/secret` and `jwt/internal_secret` paths unchanged (shared).
5. **Add the shared electro-table env/secret wiring** so the app container can reach `run-human-electro` (mirror the `RUN_ELECTRO_*` block run.human uses — copy the exact var names from `apps/run.human/.../service.hcl` if present, otherwise add `RUN_ELECTRO_DBNAME`, `RUN_ELECTRO_REGION`, and the `RUN_ELECTRO_ID`/`RUN_ELECTRO_SECRET` secrets pointing at the existing electro credential SSM paths). If run.human's service.hcl is the authority, match it exactly.
6. **Drop flash-only env** that bib does not use: remove `RUN_HUMAN_INTERNAL_URL` unless a profile lookup is needed (default: remove). Keep `AUTH_INTERNAL_URL`, `AUTH_PUBLIC_URL`, `SITE_DOMAIN`, `AWS_REGION`, `AUTH_COOKIE_DOMAIN`, `REGION_SHORT`, `NODE_ENV`, `HOSTNAME`.
7. Keep `regions = ["us-east-1", "ca-central-1", "ap-southeast-1"]`, cpu/memory, health checks, ports, and autoscaling identical to flash.

Create `VERSION.app` and `VERSION.nginx` with the same initial value run.flash uses (copy the content of run.flash's VERSION.app / VERSION.nginx; these are the starting image tags, e.g. `0.0.1`).

CRITICAL: Do not add Stripe secrets in this task — those are added in 19-02 alongside the SSM parameter creation, to keep this plan free of unresolved parameter references at plan time.

  </verify>
