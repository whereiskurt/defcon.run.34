<objective>
Build the egg-side client: a reusable module that, on the `!!!` trigger, injects the
covert stylesheet link with the flag encoded into a build-date-looking `?v=`, reads the
award back via `getComputedStyle`, fires the DC33 celebration on a win only, and STASHES
the encoded `?v=` in localStorage so an unauth fire can be claimed later — plus mount the
`!!!` trigger where a SIGNED-IN user actually lands so the full loop is demonstrable.

Purpose: CTF-09 end-to-end + the SC2 park-and-claim payoff. The read MUST be a
computed-style read (not a parsed fetch body) so a network watcher sees only a stylesheet
load. The deferred claim is CLIENT-SIDE (stash + idempotent re-fire) so the covert response
stays byte-identical across win/wrong/unauth — no nonce/cookie/header is ever returned.

PRIMARY MOUNT: `(protected)/layout.tsx` (verified: it reads the session and renders, it does
NOT redirect). The `(public)/page.tsx` landing silent-SSO-redirects signed-in users to
`/whoami` BEFORE it renders, so a signed-in trigger→covert→credit→confetti loop is NOT
demonstrable there. Mounting in the protected group layout means the egg works on every
signed-in page (matching "easter egg anywhere on the site") and a signed-in user genuinely
reaches it. A SECONDARY anon mount stays on `(public)/page.tsx` (anon users are not
redirected there) to demonstrate the unauth-park → next-signed-in-visit claim.

Output: `covert-egg.ts` (encode + inject + read-back + shouldCelebrate + localStorage
stash/claim), `EggTrigger.tsx` (the `!!!` listener that mounts CtfCelebration and, on mount,
claims any stashed flags), and the mount wiring into `(protected)/layout.tsx` (+ secondary
anon mount on `(public)/page.tsx`).
</objective>
