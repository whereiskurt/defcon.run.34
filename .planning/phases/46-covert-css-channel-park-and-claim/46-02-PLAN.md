<objective>
Build the covert stylesheet endpoint: an App Router route handler at
`/use1/assets/theme` that always answers `200 text/css` `no-store`, decodes the `?v=`
flag, credits a signed-in win through the existing judge (or parks an unauth guess),
and returns either the plain decoy sheet or the marker-bearing win sheet — with zero
network-observable tell of auth/win state.

Purpose: This is the invisibility surface itself (CTF-07 always-200 endpoint; CTF-08
identical status/type/≈size + no differential logging; CTF-09 unauth park-and-claim).
Output: the covert route + a route-level test proving the win/wrong/unauth matrix is
indistinguishable except for the award property.

CHOSEN COVERT PATH: `/use1/assets/theme` (source `src/app/(ctf)/assets/theme/route.ts`).
Reads as a themed asset, app-routed (route handler → ALB origin, not S3), and has NO
`.css` extension so a higher-precedence `*.css` static behavior cannot grab it — the
spelling Phase 48 targets with a dedicated CachingDisabled + cookie-forward behavior.
</objective>
