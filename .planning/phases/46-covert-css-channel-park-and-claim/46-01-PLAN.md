  <action>
    Create `ctf-covert-codec.ts` exporting `encodeFlag(challenge: string, guess: string): string`
    and `decodeFlag(v: string): { challenge: string; guess: string } | null`.

    Scheme (document it in a header comment, keep &lt;100 lines): length-prefix the UTF-8
    bytes of `challenge` and `guess` into a single byte buffer, interpret the buffer as a
    BigInt, append a checksum (e.g. value mod 97 folded into the low digits) and render as a
    decimal string. `decodeFlag` reverses: reject anything not matching pure decimal digits,
    parse to BigInt, verify the checksum, split the length-prefixed challenge and guess bytes,

    NEVER throw (wrap the parse in a total guard; do not rely on caller try/catch).

    The scheme must be reversible (round-trip exact) and total (all inputs map to a result or
    null). Do not use a lookup registry of flags — encode the guess bytes directly so no flag
    material is stored server-side. The decoded `challenge` is passed through unchanged to the
    caller (the route normalizes it via normalizeChallenge before judging).

    Do NOT log anything in this module — it is a pure codec.
  </action>
