<objective>
Build the run.gpx producer side of the GPX→leaderboard seam (LDBR-05). In the GPX
activation path (`confirm/route.ts`), after the status flips to "active" and only for
individually-owned files (skip GLOBAL), fetch the full GPX body from S3, decimate the
parsed track to a ~100-point `{lat,lng}` polyline in-memory, and POST an accomplishment
payload to run.human's new internal endpoint. The whole hook is best-effort: a failure
NEVER breaks the GPX save/confirm response.

Purpose: turn a real GPX upload into a leaderboard accomplishment. No run.gpx schema
change — the polyline lives only on run.human's Accomplishment.metadata.polyline (YAGNI,
per CONTEXT).
Output: pure decimation/payload lib + best-effort notify + the confirm-route hook + tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| run.gpx confirm route → S3 | Full GPX body read (own bucket, own key) — no user-controlled URL. |
| run.gpx → run.human internal endpoint | Server-to-server POST authorized by AUTH_INTERNAL_SECRET; host is fixed via service discovery (no SSRF surface). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-50-06 | Denial of service | confirm route blocked by a slow/failing notify | high | mitigate | The hook is try/catch fire-and-forget; any fetch/parse/S3 error is swallowed and the confirm response is returned regardless (best-effort, unit-proven on the notify path). |
| T-50-07 | Tampering | GLOBAL community file produces a bogus accomplishment | medium | mitigate | Guard skips `targetUserId === "GLOBAL"` — GLOBAL has no individual owner and "GLOBAL" is not a resolvable sub. |
| T-50-08 | Info disclosure | AUTH_INTERNAL_SECRET leaks via logs | low | mitigate | Secret sent only as a header; hook logs gpxFileId only, never the secret or payload. |
| T-50-09 | Spoofing / SSRF | POST target host is attacker-influenced | low | mitigate | Base URL derived from fixed env (RUN_HUMAN_INTERNAL_URL / service-discovery), never from request input — mirrors the proven social-qr.ts derivation. |
| T-50-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new package installs — @aws-sdk/client-s3 already a dependency; GetObjectCommand is an existing import elsewhere. No legitimacy gate required. |
</threat_model>
