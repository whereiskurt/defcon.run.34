<objective>
Wire the scoring-window gate (CTFT-10) into `judgeSolve` as ordered step 3 — after the unlock gate (1b), before the attempt-cap gate (2) and answer validation (3). When a flag has `scoreWindow` set and `now` (evaluated in `scoreWindow.tz` via the pure `isWithinScoreWindow`) is outside the day/time window, the judge returns the exact `NON_SOLVE` a wrong answer yields — indistinguishable, preserving the covert-channel invariant (T-53-04-01) — and never logs the guess or secret. Absent `scoreWindow` ⇒ the gate is a no-op and every shipped flag is unchanged.

Purpose: Slice 2's enforcement half. This is the only server behavior change in the phase and it is additive: a new gate that short-circuits to the existing non-solve path.

Output: `JudgeCtf.scoreWindow` + `narrowCtf` passthrough + the step-3 gate in `judgeSolve`, with a dedicated judge-gate test (inside/outside/DST/backward-compat/covert-indistinguishable).
</objective>
