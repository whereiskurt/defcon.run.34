|----------|-------------|
| server layout -> client CopyProvider | The resolved copy map crosses to the client; the token and CMS URL must NOT |
| CMS editor -> client render of copy | Copy values shown in client components must render through the safe renderer (Plan 02) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-36-08 | Information disclosure | CopyProvider prop / server->client payload | high | mitigate | Only the resolved copy map is passed to CopyProvider; copy.ts is server-only and never imported by a client component (grep gate); token/CMS URL never cross the boundary |
| T-36-09 | Elevation of privilege (XSS) | client render of a copy value with markdown | high | mitigate | Any markdown display uses the Plan 02 escape-then-whitelist renderer; no raw-HTML injection of copy in client components |
| T-36-10 | Denial of service | useCopy throwing when no provider / empty map | low | mitigate | useCopy floors to snapshot ?? key and never throws; layout always supplies a resolved map |
| T-36-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs in this plan; no legitimacy gate required |
</threat_model>
