<objective>
Build the lightweight inline markdown renderer for copy values (TOOL-05): escape HTML first, then whitelist a small set — bold, italic, links, line-breaks — with no new dependencies and identical server/client behavior. This is the phase's primary XSS surface, so the escape-then-whitelist behavior is the acceptance criteria, not an afterthought.

Purpose: Copy values are editor-controlled strings. Rendering them must be safe by construction so an organizer (or a compromised CMS) cannot inject executable HTML into any app that shows copy.
Output: `lib/copy-markdown.tsx` + a vitest spec pinning the escape and whitelist invariants.
</objective>

  <behavior>
    - Bold `**strong**` renders a <strong>; italic `*em*` renders an <em>; a line-break `\n` renders a <br/>.
    - A link `[label](https://example.com)` renders an <a> with the label text and an href of https://example.com, carrying rel="noopener noreferrer" and target="_blank".
    - An HTML-injection payload such as a script tag or an <img onerror=...> string renders as inert escaped text — no live element, no executable attribute (assert the rendered markup contains the escaped entity form and no live tag).
    - A link whose URL uses a javascript: (or data:) scheme drops the href / renders the label as plain text — no navigable dangerous URL survives.
  </behavior>
  <action>
    Create `lib/copy-markdown.tsx` exporting a pure renderer (e.g. `renderCopy(value: string): React.ReactNode`) that: (1) FIRST escapes the HTML metacharacters of the raw value (`&`, `<`, `>`, `"`, `'`) so any editor-injected markup becomes inert text; (2) THEN tokenises the escaped string and rebuilds ONLY the whitelisted inline constructs as React element nodes — `**bold**`->strong, `*italic*`->em, newline->br, and `[text](url)`->anchor. Anchors validate the URL scheme against an allowlist of http/https/mailto and otherwise render the label as plain text; every rendered anchor gets rel="noopener noreferrer" and target="_blank". Return an array of React nodes — do NOT inject raw HTML strings into the DOM. No markdown library, no sanitizer dependency; the escape-first step is what makes it safe, the whitelist is what makes it useful.
    Write `copy-markdown.test.tsx` (vitest, node env) that renders the output via renderToStaticMarkup and asserts each behavior above, including the two XSS payloads (script/onerror stays escaped; javascript: URL neutralised).
  </action>
