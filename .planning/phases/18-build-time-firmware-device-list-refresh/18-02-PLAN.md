@.planning/phases/18-build-time-firmware-device-list-refresh/18-CONTEXT.md

Current dev-download script lives at
`apps/run.flash/webapp/scripts/download-firmware.sh` and today (a) extracts
app-only `.bin` files, (b) reads the version by grepping the hardcoded
constant in `src/config/firmware.ts` — which 18-01 removes. Both must go.

Upstream data sources (build-time only — dev script only calls these on
demand, never at runtime):
- Version list: `https://api.meshtastic.org/github/firmware/list` → JSON with
  `releases.stable[0].id` (e.g. `"2.6.14.f6c3ac1"` — no leading v).
- Hardware list: `https://api.meshtastic.org/resource/deviceHardware` → JSON
  array; each entry has `architecture` (string), `hwModel`, `hwModelSlug`,
  `platformioTarget`, `displayName`, `activelySupported`, optional
  `supportLevel`, `tags`, `images`.

Tracked JSON snapshot lives at `apps/run.flash/webapp/public/data/hardware-list.json`.
Overwriting it in git is intentional (D-04) so PRs show upstream Meshtastic drift.

Recommended stays in code — do NOT touch `src/config/devices.ts` in this plan.
</context>
