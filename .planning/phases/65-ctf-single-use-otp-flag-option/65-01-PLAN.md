<objective>
Lay the additive foundation for the single-use OTP flag option: the persisted config flag (`otp.singleUse`), the lightweight `CtfOtpClaim` create-if-absent claim entity (with a DynamoDB TTL), and a runtime-pure `ctf-otp-claim` helper that carries the code-identity, the first-wins/second-loses gate, and the TTL math — all unit-tested offline with NO ElectroDB. Nothing in this plan changes judge or admin behavior yet; it is the type/entity/pure-logic seam the judge (65-02) and admin form (65-03) build on. Default-off is proven here (a `singleUse`-absent OTP seed row still builds shared).

Purpose: Deliver CTFT-16 (entity + pure helper) and the persisted half of CTFT-15 (the `otp.singleUse` config flag on the entity and the seed builder) as a self-contained, offline-testable slice — so the judge wiring lands against a settled, key-parity-locked contract.
Output: `singleUse` on the `Ctf.otp` map; the `CtfOtpClaim` entity + `CtfOtpClaimItem`; the pure `ctf-otp-claim` module; `CtfSeedOtp.singleUse`; three test additions (pure claim/identity/TTL, seed default-off, key parity).
</objective>

<artifacts_produced>
New symbols this plan introduces:
- `Ctf.otp.properties.singleUse` — an optional `boolean` on the OTP map. Absent/false ⇒ shared (the existing repeatable time-bucket path); true ⇒ the first-come single-use path the judge (65-02) branches into.
- `CtfOtpClaim` (entity) — pk `[challenge]`, sk `[codeHash]`; attrs `claimedBy`, `claimedAt`, `ttl` (DynamoDB TTL epoch seconds), `createdAt`. Create-if-absent is the claim: `attribute_not_exists` on the key ⇒ exactly one concurrent writer wins. NO resolver `.mjs` mirror.
- `CtfOtpClaimItem` — hand-authored item type (mirrors `CtfCodeItem` + a `ttl?: number`).
- `otpCodeHash(rawGuess: string): string` — the stable single-use code identity; delegates to `hashAnswer` (salted SHA-256; raw never stored). Same code → same hash.
- `otpClaimTtlSeconds(nowMs: number, otp?: { period?: number; skew?: number }): number` — `floor(nowMs/1000) + period·(skew+2)`, applying the meshtk defaults (period 120, skew 1) when unset.
- `applyOtpClaim(claims: Map<string,{claimedBy:string}>, codeHash, user): { claimed: boolean; claimedBy?: string }` — the PURE create-if-absent model (the offline twin of `CtfOtpClaim.create`), reused by the 65-02 judge test fake.
- `resolveOtpClaimOutcome(result: { claimed: boolean }): "credit" | "non-solve"` — the first-wins/second-loses decision.
- `CtfSeedOtp.singleUse?: boolean` — the seed-builder mirror of the config flag.
</artifacts_produced>
