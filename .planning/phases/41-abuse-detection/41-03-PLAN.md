## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EventBridge → Lambda | Only the named rule may invoke (aws_lambda_permission source_arn). |
| Lambda role → AWS APIs | Athena/Glue/S3/SNS access must be ARN-scoped, not account-wide. |
| Lambda → reused SNS topic | Publish restricted to the single Phase 40 topic ARN. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-41-05 | Elevation of Privilege | Lambda IAM role | high | mitigate | Per-Sid least-privilege policy: Athena scoped to the one workgroup, Glue scoped to the one database/table, S3 scoped to the ALB-log bucket (read) + results bucket (rw), `sns:Publish` scoped to the exact reused topic ARN — no wildcards. |
