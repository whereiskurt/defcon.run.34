<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ALB access logs (S3) → Athena/Glue | Log rows contain attacker-controlled strings (User-Agent, request URL); read as column data by Athena. |
| Athena workgroup → results S3 bucket | Query output written to S3; must not be world-readable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-41-01 | Tampering | Glue table over attacker-influenced log fields | low | mitigate | Log fields are read strictly as column DATA; no query text is built from log content (SQL is authored in Plan 02 with placeholders the Lambda controls). |
| T-41-02 | Denial of Service | Athena scan cost | medium | mitigate | Workgroup `bytes_scanned_cutoff_per_query` cap + partition projection + (Plan 03) lookback window bound each run to a small recent slice. |
| T-41-03 | Information Disclosure | Athena results S3 bucket | high | mitigate | Public access block (all four true) + SSE-S3 on the results bucket; 7-day results lifecycle. |
| T-41-SC | Tampering | npm/pip/cargo installs | low | accept | No third-party package installs in this plan (pure Terraform). Lambda plans use runtime-provided AWS SDK v3 + node:test builtins — no install, no legitimacy gate. |
</threat_model>
