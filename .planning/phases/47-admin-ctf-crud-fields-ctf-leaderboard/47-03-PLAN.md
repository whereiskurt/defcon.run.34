<objective>
Build the CTF-only admin leaderboard (CTF-11): a gated page under the existing `(protected)/admin` group that ranks users by `RunUser.ctfScore` (desc, showing `ctfSolves`) and drills into a selected challenge's `CtfSolve` rows (user, ordinal, points, first-blood, channel, solvedAt), plus an admin-gated CSV export that escapes formula-injection in attacker-influenced fields. It reuses the Phase-43 `scanAllRunUsers` read and the existing `ADMIN_GROUPS` 404-on-denial gate, and matches the AdminConsole HeroUI/teal chrome. Reachability from the `q.defcon.run/admin/leaderboard` host is Phase 48 — this phase renders it under run.human's normal `/use1` basePath and links it from AdminConsole.

Purpose: give organizers a live CTF standings + per-challenge solve view, and expose the read shape the DC33 total-score mapper (separate worktree) will consume.
Output: `ctf-leaderboard.ts` read/assembly module + tests, the gated leaderboard page, the gated CSV route, and an AdminConsole link.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /admin/leaderboard page + /api/admin/ctf-leaderboard | admin-only surfaces reading RunUser standings + CtfSolve rows; must not be reachable by non-admins |
| exported CSV → spreadsheet app | attacker-influenced displayName / challenge strings become cells opened in Excel/Sheets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-09 | Elevation of Privilege | leaderboard page + CSV route reachable by non-admin | high | mitigate | Reuse the existing ADMIN_GROUPS gate: page via gateAdminPage (notFound on denial), route via requireGroups + revalidateGroups(authUserId) → bare 404; no 401/403 leak |
| T-47-10 | Tampering | CSV formula injection via displayName / challenge | high | mitigate | leaderboardCsv passes every cell through guardFormula (OWASP `= + - @ \t \r` prefixing) composed over the RFC-4180 csvCell; asserted by Task 1 test |
| T-47-11 | Information Disclosure | leaderboard leaking PII (emails) | low | accept | The leaderboard shows only displayName + score + solve metadata — no email/PII column is rendered or exported (emails stay in the Phase-43 users report) |
| T-47-12 | Information Disclosure | CSV cached at the edge | medium | mitigate | Route returns Cache-Control: no-store (Phase 48 also sets CachingDisabled at CloudFront); force-dynamic prevents Next caching |
</threat_model>
