<objective>
Close the application half of CR-01 and the builder-side warnings that make a slow build
dangerous.

The route's header currently asserts that no CloudFront behaviour maps the internal path
and that the shared secret is "the second layer, not the only one". Both claims are false
in this deployment: a raw POST from the open internet returns the handler's own body, so
the request traversed CloudFront and the ALB and reached Next.js. The secret is the ONLY
control, compared with a short-circuiting string comparison, on an endpoint where each
authorized call launches an unbounded table scan plus one S3 read per con-day run on a
single-task service.

Also closes WR-03 (`maxDuration` is inert under standalone output on ECS, so the documented
contract with the Terraform timeout binds nothing), WR-05 (silent MAX_RUNS truncation, and
S3 reads paid for rows that are then discarded) and IN-01/IN-04.

Purpose: this is the con-week availability half of the phase's exposure. The edge block
(plan 71-13) is the other half; neither is sufficient alone.

Output: an endpoint that does not advertise itself, cannot be timing-probed, fails closed
loudly rather than silently, and a builder with a bound that actually exists.
</objective>
