<objective>
Wire the judge's `wordlist` answer type (CTFT-13): extend the store seam with an atomic single-use `claimCode` op (a conditional `attribute_not_exists(claimedBy)` patch on the 56-01 `CtfCode` row), add the `wordlist` branch to `judgeSolve`, and prove the two-claimers-one-wins race at the store seam. A used/unknown code is a non-solve indistinguishable from a wrong answer; a valid claim scores through the existing accrue/ledger path and never logs the guess. The covert CSS path stays byte-identical.

Purpose: Deliver the single-use-code judge behavior — the concurrency-correct heart of Slice 3 — additively, without disturbing static/otp flags or the covert channel.
Output: `claimCode` store op + `wordlist` branch in `ctf-judge.ts`; `isRepeatable` wordlist recognition in `ctf-flag-types.ts`; a wordlist judge test (race + indistinguishability + scoring) and a covert-invariant grep gate.
</objective>

- `CtfStore.claimCode?(args:{ challenge; codeHash; user; claimedAt }): Promise<{ claimed: boolean }>` — optional/additive store op (mirrors the flag-types optional-op discipline; absent op ⇒ locked non-solve).
