<objective>
Add the admin **Wordlist** answer type (CTFT-14): a third segment in the Answer-type section that reveals a write-only, add-only bulk textarea; on save the non-empty lines are hashed server-side (same salt scheme as answers) and appended to the 56-01 `CtfCode` pool, and an edit shows a read-only loaded/unclaimed count. Plaintext codes are never stored and never round-tripped to the client. Reuses the Phase-54 form seams — no fork.

Purpose: Give operators a first-class way to bulk-load single-use codes and see pool status, closing the Slice-3 loop end to end (admin → CtfCode → judge claim from 56-02).
Output: `CtfInput.codes` + a pure `hashCodeBatch` + the add-only bulk-load write + `getCtfCodeCounts` in `qr-admin.ts`; wordlist widening + `codeCounts` in `ctf-form-model.ts`; the Wordlist segment + bulk textarea + count line in `CtfForm.tsx`; the edit page attaches counts.
</objective>
