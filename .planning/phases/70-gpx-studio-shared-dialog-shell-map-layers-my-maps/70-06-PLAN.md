## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local workstation → GitHub Actions | Workflow dispatches trigger a production build and deploy |
| CI → ECR / ECS / CloudFront | The release pushes an immutable image tag and rolls the ECS service |
| SSM Parameter Store → local probe process | The mapbox public token is read with decryption into an environment variable |
| live prod → probe browser | The probe stubs authenticated endpoints locally; it never writes to prod |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-SC | Tampering (supply chain / release integrity) | buildpub.yml dispatch | high | mitigate | `gh run list --workflow=buildpub.yml` is checked for in-flight run.gpx builds BEFORE dispatch (immutable-ECR-tag race), and the squash merge is confirmed `MERGED` before the release is dispatched so CI cannot build an unintended commit. No package-manager install occurs in this phase, so no `[ASSUMED]`/`[SUS]` package legitimacy checkpoint applies |
| T-70-15 | Tampering (unreviewed infrastructure change) | deploy path | high | mitigate | Deployment is workflow-dispatch only; no local `terragrunt apply`, and `--with-terragrunt` is never passed to any release command (AGENTS.md Essential Rule 4), asserted in the acceptance criteria |
| T-70-16 | Information disclosure | mapbox token in the probe | medium | mitigate | The token is a PUBLIC `pk.` mapbox token read at run time into an env var; it is never written into the committed probe script or into either transcript — transcripts are grep-checked for `pk.` before commit |
| T-70-17 | Repudiation (false green) | prod verification | medium | mitigate | The identical probe is run BEFORE the deploy and must fail; only then is a post-deploy 12/12 accepted, so a probe that silently asserts nothing cannot pass |
