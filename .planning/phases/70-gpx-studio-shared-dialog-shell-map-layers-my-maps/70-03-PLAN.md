<objective>
Re-skin the three Map Layers section components onto the shared kit (DLGS-02) and
delete their native tooltips (DLGS-04): PublicOverlays (check-ins + route
groups), MyConRuns (per-con-day runs), CommunityRoutes.

Purpose: today these three files each hand-roll the same collapse header three
slightly different ways, and PublicOverlays' route rows carry the native tooltips
that cause the hover stutter.

Output: three modified components whose template top level is Section cards only,
ready for plan 05 to place directly into the dialog body. Layer classes, filter
semantics and store contracts are untouched.

## Interface contract with plan 05 (LayerControl host)

After this plan, each component renders its OWN top-level `<Section>` card(s) and
NO outer wrapper:
- `PublicOverlays.svelte` → optional `All Runners` header-only Section, optional
  `User Check-ins` Section, then one Section per entry of `$publicOverlayGroups`
  (which is where the `DEF CON 34 Routes` and `Rabbit Routes` labels come from).
- `MyConRuns.svelte` → exactly one `My DEF CON Runs` Section containing one
  `variant="plain"` sub-Section per con-day.
- `CommunityRoutes.svelte` → exactly one `Community Routes` Section.

Plan 05 therefore deletes LayerControl's `p-2 ml-1` wrapper divs, its
`<Separator>` rules and its hand-written `My DEF CON Runs` label div (currently
LayerControl.svelte lines 509-513), and keeps only the `{#if}` guards.
</objective>
