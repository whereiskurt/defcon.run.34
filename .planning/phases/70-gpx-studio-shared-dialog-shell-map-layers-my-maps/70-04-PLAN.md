## Hard constraint: this file is LEGACY mode

`CloudStorage.svelte` is NOT a runes component (see its own comment at line 79:
"legacy-mode component — plain lets are reactive here, no runes"). It uses plain
`let` plus `$:` reactive statements in ~30 places. Introducing a single `$state`,
`$derived`, `$effect` or `$props` anywhere in this file forces the whole
component to runes mode and silently breaks those bindings. Every new piece of
state in this plan is a plain `let`; every new derivation is a `$:` statement.
Consuming the runes-mode kit components from a legacy component is fine — mode is
per-file — and `{#snippet}` blocks are template syntax available in both modes.
</objective>
