## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-35-SC | Tampering | `@aws-sdk/client-s3` install (no RESEARCH audit table) | high | mitigate | Blocking-human legitimacy checkpoint (first task) verifies the official `@aws-sdk`-scoped package on npmjs.com before install; pinned to the same `^3.x` major as the two already-trusted `@aws-sdk` deps. |

| T-35-04 | Elevation of Privilege / Tampering | lifecycle S3 write runs with S3 creds | medium | mitigate | Write path gated on `CMS_MODE === 'master'` (workers never write) and reuses the existing least-privilege `S3_MEDIA_*` media creds (no new IAM surface, no new bucket).
