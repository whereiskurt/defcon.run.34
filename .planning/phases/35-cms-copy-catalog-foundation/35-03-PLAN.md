<objective>
Gate the `ui-string` catalog behind the existing read-only API token and deny the Public role, mirroring the posture already applied to `route`/`event`/`point-of-interest`. Implements COPY-03.

Purpose: App consumers (the Phase 36 toolkit) read the catalog with the `run-human-internal` read-only token; the anonymous Public role cannot read it, and the read-only token cannot write it. This is a small, surgical change to `revokePublicPermissions()` plus an empirical verification that the read-only token already covers `ui-string` find/findOne (Strapi read-only tokens grant find/findOne dynamically across content types).

Output: One extended array in `src/index.ts`, plus documented runtime verification of the 200/403 matrix.
</objective>
