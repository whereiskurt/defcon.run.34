<objective>
Create the `ui-string` Strapi 5 collection content type — the producer-side catalog data model for the v1.9 CMS copy catalog. This is the schema + core controller/router/service that every later Phase 35 plan (uniqueness backstop, S3 export, permissions) builds on.

Purpose: Give organizers an authorable `(key, locale, value)` row with a namespace and notes, editable in Strapi's default content-manager, with a stable table name (`ui_strings`) and REST resource (`/api/ui-strings`) that downstream plans depend on. Implements COPY-01 (authorable row) and COPY-04 (multi-lingual-ready `locale`, only `default` populated in v1).

Output: A new `src/api/ui-string/` API directory mirroring the existing `route` API, with `draftAndPublish: false`.
</objective>
