<task type="auto">
  <name>Task 1: Create CheckInHistory component</name>
  <files>apps/run.human/webapp/src/components/profile/CheckInHistory.tsx</files>
  <action>
Create a new client component `CheckInHistory.tsx` in the profile components directory. This component receives `checkInCount` (number) as a prop and handles its own data fetching and state.

**Component structure:**

1. **State management:**
   - `checkIns: CheckInItem[]` -- current page's check-ins
   - `cursor: string | null` -- for pagination
   - `currentPage: number` -- 1-based page number
   - `pageCache: Map<number, { data: CheckInItem[], cursor: string | null }>` -- cache fetched pages
   - `selectedId: string | null` -- currently highlighted check-in ID (for two-way linking)
   - `isOpen: boolean` -- collapsible section state, default `true` (expanded)
   - `loading: boolean` -- fetching state

2. **Data fetching:**
   - On mount, fetch first page: `GET /api/checkins?limit=5` using `apiUrl()` helper
   - On page change, check cache first, otherwise fetch with cursor from previous page's response
   - IMPORTANT: Cursor-based pagination means page 3 requires knowing page 2's cursor. Cache pages as they are fetched. Only allow forward navigation to pages whose cursor is known, or backward to cached pages.
   - Store each page result in `pageCache` keyed by page number
   - Compute total pages from `Math.ceil(checkInCount / 5)`

3. **Sequential numbering:**
   - Latest check-in = checkInCount (highest number)
   - Second latest = checkInCount - 1, etc.
   - For page N (1-based): first item number = checkInCount - ((N-1) * 5)
   - Each subsequent item on the page decrements by 1

4. **Leaflet map (top of section, 350px height):**
   - Use dynamic import for react-leaflet components to avoid SSR issues: `const MapContainer = dynamic(() => import('react-leaflet').then(m => m.MapContainer), { ssr: false })` -- or use a simpler approach: wrap the entire map in a check for `typeof window !== 'undefined'` and lazy-load the leaflet CSS
   - Import leaflet CSS in the component: `import 'leaflet/dist/leaflet.css'` and `import 'leaflet-defaulticon-compatibility/dist/leaflet-defaulticon-compatibility.css'` and `import 'leaflet-defaulticon-compatibility'`
   - Use OpenStreetMap dark-themed tiles: `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png` (matches the app's dark theme)
   - For each check-in on the current page, render:
     - A `Marker` at `averageCoordinates` using a custom `divIcon` showing the sequential number in a colored circle (blue/primary for public, gray for private). The divIcon HTML: `<div style="background:${color};width:28px;height:28px;border-radius:50%;display:flex;align-items:center;justify-content:center;color:white;font-weight:bold;font-size:12px;border:2px solid white">${number}</div>`
     - A `Circle` at `averageCoordinates` with radius = `bestAccuracy` (in meters), semi-transparent fill matching the marker color
     - A `Popup` showing: check-in number, relative time (use a simple helper like `formatRelativeTime`), accuracy, privacy status
   - Auto-fit map bounds to current page's markers using `map.fitBounds()` with padding. Use a `useEffect` that gets the map instance via `useMap()` in a child component (e.g., `MapBoundsUpdater`) and calls `fitBounds` when check-ins change.
   - When `selectedId` changes (from list click), fly to that marker and open its popup

5. **Check-in list (below map):**
   - Render each check-in as a clickable row/button
   - Format: `"#N . X ago . +/-Ym . Privacy"` where N is sequential number, X is relative time, Y is bestAccuracy rounded to nearest meter
   - Color-code privacy: use HeroUI `Chip` with `color="primary"` for Public, `color="default"` for Private
   - On click: set `selectedId` to that check-in's ID (triggers map pan/popup)
   - Highlight the selected row with a subtle background (e.g., `bg-primary/10`)
   - Each row should have an `id` attribute or ref for scroll-into-view when marker is clicked

6. **Map-to-list linking:**
   - When a marker popup opens (via `eventHandlers={{ click: ... }}`), set `selectedId` and scroll the corresponding list row into view using `document.getElementById(...)?.scrollIntoView({ behavior: 'smooth', block: 'nearest' })`

7. **HeroUI Pagination at bottom:**
   - `<Pagination total={totalPages} page={currentPage} onChange={handlePageChange} />`
   - `showControls` prop for prev/next arrows

8. **Empty state (checkInCount === 0):**
   - Show map centered on Las Vegas: `[36.17, -115.14]` at zoom 12
   - Overlay message on the map: absolutely positioned div with semi-transparent background saying "No check-ins yet -- use GPS Check-in from the menu to get started"
   - No list or pagination rendered

9. **Collapsible section wrapper:**
   - Follow the exact pattern from whoami/page.tsx (QR/Quotas sections):
     - `<Card className="glass-card overflow-hidden">`
     - `<CardBody className="px-5 py-3">`
     - Button with ChevronDown/ChevronRight toggle
     - Section header text: `Check-ins ({checkInCount})`
     - Conditionally render content when `isOpen` is true

10. **Relative time helper:**
    - Create a simple `formatRelativeTime(timestamp: number): string` function inline
    - Handles: "just now" (< 1 min), "X min ago", "X hours ago", "X days ago", "X months ago"
