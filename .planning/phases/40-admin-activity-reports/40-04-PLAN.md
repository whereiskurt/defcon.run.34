## Event -> metric map (LOCKED — namespace DefconRun/Activity)

| Filter pattern | Metric name | Source /ecs group |
|---|---|---|
| `{ $.evt = "auth.signup" }` | `Signups` | run.auth |
| `{ $.evt = "auth.login" }` | `Logins` | run.auth |
| `{ $.evt = "gpx.file.create" }` | `GpxUploads` | run.gpx |
| `{ $.evt = "gpx.file.publish" || $.evt = "gpx.share.request" || $.evt = "gpx.share.accept" }` | `GpxShares` | run.gpx |
| `{ $.evt = "gpx.map.view" }` | `MapViews` | run.gpx |
| `{ $.evt = "human.checkin" }` | `Checkins` | run.human |
| `{ $.evt = "human.upload" }` | `Uploads` | run.human |
| `{ $.evt = "strava.ratelimit" }` (metric value = `$.meta.usage`) | `StravaRateLimitUsage` | run.gpx |

**Strava field contract (LOCKED with 40-02, same wave):** the `strava.ratelimit` line carries numeric
`meta.usage` and `meta.limit`. The `StravaRateLimitUsage` filter's `metric_transformation.value` MUST
be `$.meta.usage` (not `1`) — binding to any other path yields a silently always-empty Strava widget.
