## Event line contract (LOCKED — identical to 40-01)

logEvent emits one `JSON.stringify` line to stdout: keys `evt`, `userId`, `email`, `ip` (first
`x-forwarded-for` hop), `ua`, `meta`. Wrap in try/catch, return void, never block the request path.

## Strava rate-limit meta contract (LOCKED — cross-plan contract with 40-04)

The `strava.ratelimit` line MUST carry exactly these two numeric meta fields (40-04 runs in the same
wave and cannot read this plan's SUMMARY, so the names are fixed here, not left to executor discretion):
- `meta.usage` — numeric, the 15-min-window value (first hop of the comma pair) of `X-RateLimit-Usage`
- `meta.limit` — numeric, the 15-min-window value (first hop of the comma pair) of `X-RateLimit-Limit`

40-04's metric filter binds its metric value to `$.meta.usage` — that JSON path must resolve or the
`StravaRateLimitUsage` widget (AR-08c) is silently always-empty.
