<objective>
Create the one-off backfill that populates `MeshRadio` from every existing `RunUser.meshtasticRadios[]` entry, so the entity is fully seeded before meshtk flips `fallback=none` at deploy time (spec §8, sequencing in CONTEXT). Idempotent, re-runnable, dry-run-by-default — precon test data means "a mistake is re-runnable" (spec §8a).

Purpose: Without the backfill, radios registered before this phase have no MeshRadio row and would miss under `fallback=none`. This closes that gap.
Output: `scripts/backfill-mesh-radios.mts` + an idempotency/conversion unit test.
</objective>
