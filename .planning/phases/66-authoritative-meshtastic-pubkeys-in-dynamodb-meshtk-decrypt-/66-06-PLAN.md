<objective>
Build meshtk's `internal/keycache` package: a process-wide, cache-first resolver that returns a sender node's authoritative X25519 pubkey (0x hex) from the `MeshRadio` DynamoDB entity via direct `GetItem` — mirroring `internal/credcache`'s `CacheAuthenticator` (Otter cache + singleflight + negative caching + circuit breaker) but replacing `Scan` with `GetItem`. This is the read engine that satisfies the OVERRIDING constraint: fleet-wide at most ~one DDB read per node per 1-2 min TTL, independent of packet/client volume.

Purpose: The keycache is the load-bounded, poisoning-resistant key source. Plan 66-07 wires it into the decrypt/reply paths.
Output: `internal/keycache/{types,cache,store,resolver}.go` + ported tests + a Go key-parity test.
</objective>
