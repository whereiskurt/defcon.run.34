<objective>
Give run.human a single shared admin gate (page + API + CSV all use it) that mirrors
the run.bib `admin-gate.ts` idiom, PLUS a synchronous fresh-claims revalidation so a
just-revoked admin cannot linger inside the ~5-min JWT staleness window (ADMN-01).
The gate maps denial to a 404 (route non-disclosure) — the callers (Plans 04, 05)
translate the gate result into `notFound()` / a bare 404 Response.

Purpose: One correct, reusable authorization primitive for the whole phase.
Output: `lib/admin-gate.ts` + an exported `revalidateAdmin` from `config/auth.ts`.
</objective>
