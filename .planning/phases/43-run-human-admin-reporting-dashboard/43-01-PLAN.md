<objective>
Add a read-only, internal-secret-gated bulk quota endpoint on run.auth that returns
per-user consumption for a single quota type in ONE query over the existing
`byQuotaRemaining` GSI. This is the ONLY cross-app addition in Phase 43 and the
source signal for "who uses gpx a lot" (ADMN-04). run.human joins the result by
`userId`.

Purpose: Enable sorting/filtering gpx usage across ALL users without N per-user calls.
Output: `listQuotaByType` service function + `by-type/[quotaId]` internal route.

NO DynamoDB schema/table/GSI change — reuses the existing `byQuotaRemaining` index on
the run.auth quota table (`user-quota.ts:83-88`). Any touch under `src/entities/` here
is read-only; this plan does not touch entities at all.
</objective>
