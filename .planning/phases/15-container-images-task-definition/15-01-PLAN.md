Create the Mosquitto container with Alpine base, entrypoint-generated config, and ACL:

**apps/mqtt/mosquitto/Dockerfile.mosquitto:**
- `FROM alpine:3.21` (not eclipse-mosquitto official image per CONTEXT.md decision)
- Install mosquitto package: `apk add --no-cache mosquitto mosquitto-clients`
- Create directories: `/mosquitto/config`, `/mosquitto/data`, `/mosquitto/log`
- COPY `entrypoint.sh` to `/entrypoint.sh` and `chmod +x`
- COPY `acl.conf` to `/mosquitto/config/acl.conf`
- EXPOSE 1884
- HEALTHCHECK: `CMD mosquitto_sub -h localhost -p 1884 -t '$SYS/broker/uptime' -C 1 -W 3 || exit 1`
  (Uses mosquitto_sub to verify broker is responding, 3-second timeout, single message)
- ENTRYPOINT `["/entrypoint.sh"]`

**apps/mqtt/mosquitto/entrypoint.sh:**
Bash script that generates mosquitto config and passwd file from environment variables at startup:

```bash
#!/bin/sh
set -e

# Generate mosquitto.conf
cat > /mosquitto/config/mosquitto.conf << EOF
# Mosquitto configuration - generated by entrypoint.sh
listener 1884 0.0.0.0
allow_anonymous false
password_file /mosquitto/config/passwd
acl_file /mosquitto/config/acl.conf

# Logging to stdout for CloudWatch
log_dest stdout
log_type all
connection_messages true

# Message limits
message_size_limit 1024

# Connection limits
max_connections ${MQTT_MAX_CONNECTIONS:-1000}
max_keepalive 65535

# No persistence (ephemeral messages)
persistence false
EOF

# Generate passwd file from environment variables
# Each service account: MQTT_{NAME}_USERNAME and MQTT_{NAME}_PASSWORD
touch /mosquitto/config/passwd

# meshtk-proxy service account
mosquitto_passwd -b /mosquitto/config/passwd "${MQTT_MESHTK_USERNAME:-meshtk-proxy}" "${MQTT_MESHTK_PASSWORD}"

# meshobserv service account
mosquitto_passwd -b /mosquitto/config/passwd "${MQTT_MESHOBSERV_USERNAME:-meshobserv}" "${MQTT_MESHOBSERV_PASSWORD}"

# ghosts service account
mosquitto_passwd -b /mosquitto/config/passwd "${MQTT_GHOSTS_USERNAME:-ghosts}" "${MQTT_GHOSTS_PASSWORD}"

echo "[mosquitto] Config generated, starting mosquitto..."
exec mosquitto -c /mosquitto/config/mosquitto.conf
```

The entrypoint expects these environment variables (injected via ECS secrets from SSM):
- `MQTT_MESHTK_PASSWORD` (required)
- `MQTT_MESHOBSERV_PASSWORD` (required)
- `MQTT_GHOSTS_PASSWORD` (required)
- `MQTT_MAX_CONNECTIONS` (optional, defaults to 1000)
- Usernames default to service names but can be overridden

**apps/mqtt/mosquitto/acl.conf:**
```
# ACL for MQTT service accounts
# All service accounts get full read/write access to all topics

# meshtk-proxy: handles all external client traffic
user meshtk-proxy
topic readwrite #

# meshobserv: subscribes to all topics for node tracking
user meshobserv
topic readwrite #

# ghosts: publishes simulated node data
user ghosts
topic readwrite #
```

**Important:** Do NOT use `allow_anonymous true` anywhere. Do NOT add WebSocket listener. Do NOT enable persistence. These are locked decisions from CONTEXT.md.
