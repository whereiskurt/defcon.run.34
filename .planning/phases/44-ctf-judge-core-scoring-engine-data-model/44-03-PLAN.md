<objective>
Build the `judgeSolve` core (CTF-03) — the single function both future front doors (Phase 45 visible claim, Phase 46 covert CSS) call — and the log-hygiene builder (CTF-04). The judge runs the LOCKED 7-step flow: load `Ctf` → attempt-cap/rate-limit → hashed-answer validate → conditional-put claim → atomic ordinal → score → accrue rollups. It is idempotent, cap-safe under concurrency, never throws on bad input, and never logs the raw guess.

Purpose: this is the load-bearing correctness crux of the whole milestone. It is built behind an injectable `CtfStore` seam + injectable clock so the concurrency/idempotency guarantees are proven against a fake in-memory store — no live DynamoDB in the test path.

Output: `src/lib/ctf-log.ts`, `src/lib/ctf-judge.ts`, and the judge test suite.
</objective>
