<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anon client → /ctf/claim | The scanner's `?c=&v=` query params are fully attacker-controlled; the route is public and unauthenticated. |
| browser → nonce cookie | The client-set `ctf_pending` cookie is untrusted on the round trip back to the claim page. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-05 | Information disclosure | page.tsx logging | high | mitigate | The page performs NO logging; the raw guess `v` is never passed to a logging API. Enforced by the `grep -c` hygiene gate returning 0. Credit paths reuse the hygienic `judgeSolve`/`ctfJudgeLog`. |
| T-45-06 | Elevation of privilege | claim/park attribution | high | mitigate | Credit is keyed to the server-resolved `session.user.authUserId` (never the guess, never a client-supplied id); `judgeSolve` conditional-put makes a double claim (refresh/re-scan) re-show the prior award, never double-score. |
| T-45-07 | Spoofing | authUserId source | medium | mitigate | Player identity read ONLY from the server `auth()` session; the page never trusts an id from the query/cookie. Uses `authUserId`, not the adapter `session.user.id` (namespace-mismatch bug class). |
| T-45-08 | Tampering | ctf_pending nonce cookie | low | accept | The cookie holds only an unguessable random nonce mapping to an already-parked hash; a forged/expired nonce finds no `CtfPending` row → no-op. No secret is stored client-side. |
| T-45-09 | Denial of service | unbounded park writes | low | accept | Each anon hit writes one TTL-bounded (`30d`) `CtfPending` row; DynamoDB TTL reaps them. Acceptable pre-con volume; admin CRUD/limits are Phase 47. |
</threat_model>
