# Phase 38 — UI Design Contract

> Visual and interaction contract for the Custom Copy Admin page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Surface context (read first):** This is a page rendered **inside the Strapi 5.6 admin panel** (mounted via the `src/admin` injection — CONTEXT D-01), NOT a standalone or brand-styled app. The design system is **`@strapi/design-system`** (bundled transitively via `@strapi/strapi ^5.6.0`). All spacing, typography, color, focus states, light/dark theming, and RTL derive from **Strapi's admin theme tokens** — this contract does NOT invent a bespoke palette, font stack, or spacing scale. The token values below are Strapi's own defaults, recorded so the executor and checker have concrete numbers; the implementation must consume them via the theme (`theme.spaces[n]`, `<Typography variant>`, `theme.colors.*`), never as hardcoded literals. The page must visually read like Strapi's existing content-manager list view.

## Spacing Scale

Strapi exposes spacing via `theme.spaces[n]` (consume by index, do not hardcode px). Values below are Strapi defaults — all multiples of 4.

| Token | Strapi ref | Value | Usage in this page |
|-------|-----------|-------|--------------------|
| xs | `spaces[1]` | 4px | Icon-to-label gap inside buttons |
| sm | `spaces[2]` | 8px | Gap between toolbar controls; cell inner padding |
| md | `spaces[3]` | 12px | Table cell vertical padding (row density) |
| md+ | `spaces[4]` | 16px | Toolbar-to-grid gap; default control spacing |
| lg | `spaces[5]`–`spaces[6]` | 20–24px | ContentLayout horizontal padding |
| xl | `spaces[7]` | 32px | HeaderLayout vertical rhythm |
| 2xl | `spaces[8]`+ | 40px+ | Empty-state block padding |

Exceptions: none — the page uses only theme spacing indices. Growable `<Textarea>` value cells expand vertically in content-driven increments (min ~2 rows), not on the fixed scale; this is component-intrinsic and acceptable.

## Typography

Applied via `<Typography variant="…">` (Strapi variants) — do NOT set raw font-size/weight. Values are Strapi defaults, recorded for the checker.

| Role | Strapi variant | Size | Weight | Line Height | Where used |
|------|---------------|------|--------|-------------|------------|
| Page title | `alpha` | 32px | 600 (semiBold) | 1.25 | HeaderLayout title ("Copy Catalog") |
| Column label | `sigma` | 11px, uppercase, letter-spaced | 600 | 1.45 | `<Th>` header cells (label · locale · value) |
| Body / cell value | `omega` | 14px | 400 (regular) | 1.43 | Default cell text, textarea content, select values |
| Secondary / hint | `pi` | 13px | 400 | 1.33 | Row error text, subtitle, add-row key-prefix hint |

Font weights used: **400 (regular)** for content, **600 (semiBold)** for the page title and column labels. Two weights only. No custom fonts.

## Color

Consume via `theme.colors.*` so light/dark theme + contrast are automatic. Hex values are Strapi's **light** theme defaults, recorded for the checker; dark theme resolves through the same tokens.

| Role | Strapi token | Light hex | Usage |
|------|-------------|-----------|-------|
| Dominant (60%) | `neutral0` | #FFFFFF | Page/content surface, table body, editable cell background |
| Secondary (30%) | `neutral100` / `neutral150` | #F6F6F9 / #EAEAEF | Toolbar band, `<Thead>` background, row dividers/borders, hover rows |
| Accent (10%) | `primary600` | #4945FF | Primary "Save" button fill, focus rings, `SingleSelect` active state, dirty-row left-edge marker |
| Destructive | `danger600` / `danger700` | #D02B20 / #B72B1A | Per-row conflict: cell border + inline error text; save-failed banner accent |

Accent reserved for: the **Save** primary button, keyboard focus rings, the active/open state of the namespace `SingleSelect`, and the dirty/new-row indicator (a thin `primary600` left border or subtle `primary100` tint on changed rows). Accent is NOT used for the "Add row" button (secondary/tertiary variant), body text, or table chrome.

Destructive `danger600` is reserved for **validation feedback only** (conflict borders, inline error copy, the atomic-reject banner). There is no destructive *action* in v1 (see Copywriting).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Page title | Copy Catalog |
| Page subtitle | Edit UI copy strings live — changes propagate to all regions within ~15 minutes. |
| Namespace filter label | Namespace |
| Namespace filter default option | All namespaces |
| Primary CTA | **Save** (commits the dirty + new rows as one batch) |
| Secondary action | **Add row** (with `Plus` icon) |
| Save — disabled hint (no changes) | Nothing to save |
| Save — in-progress | Saving… |
| Save — success toast | Copy saved. Changes will reach all regions within ~15 minutes. |
| Empty state heading (catalog empty) | No copy strings yet |
| Empty state body | Add your first row to start editing UI copy. |
| Filtered-empty heading | No strings in this namespace |
| Filtered-empty body | Choose "All namespaces" or add a row to this namespace. |
| Error banner (atomic reject) | Save failed — nothing was written. Fix the highlighted rows and try again. |
| Row error — duplicate pair | This label + locale already exists. Each label must be unique per locale. |
| Row error — bad namespace prefix | Label must start with a valid namespace: common, human, auth, gpx, bib, or flash. |
| Row error — empty required field | Label and value are required. |
| Load error | Couldn't load the copy catalog. Refresh to try again. |

**Column header note:** the `key` column is **labelled "Label"** in the header (per the design spec / CONTEXT D-07), even though the underlying field is `key`. Value cells show **raw markdown source** — no live preview in v1.

**Add-row behavior copy:** under an active namespace, a new row pre-fills the key with the namespace prefix (e.g. `bib.`) and the editor types only the tail; under "All namespaces" the key starts blank and the editor types the full dotted key.

**Destructive actions:** none in v1. There is no row-delete control (upsert + edit + add only). The only guard is an optional "unsaved changes" prompt if the editor navigates away with dirty rows — copy: "You have unsaved changes. Leave without saving?" No confirmation dialog for Save itself.

## Layout & Component Inventory

Composition prescription (Claude's Discretion D per CONTEXT confirmed toward Strapi `<Table>`):

**Page shell**
- `Page.Main` / `Layouts.Root` → `Layouts.Header` (title "Copy Catalog" + subtitle) → `Layouts.Content`.
- Registered via `addMenuLink` (menu label: "Copy Catalog") pointing at `src/admin/pages/CopyCatalog.tsx`.

**Toolbar (above grid, single `Flex` row, `gap={spaces[2]}`, `justifyContent="space-between"`)**
- Left: `SingleSelect` (label "Namespace") with options: `All namespaces`, `common`, `human`, `auth`, `gpx`, `bib`, `flash`. Client-side filter over the already-loaded catalog (D-04).
- Right cluster: `Button` variant `secondary` startIcon `<Plus/>` "Add row"; `Button` variant `default` (primary) "Save", disabled when no dirty/new rows.

**Grid (`Table` from `@strapi/design-system`)**
- `Thead` → `Tr` → three `Th`: **Label** · **Locale** · **Value** (variant `sigma`).
- `Tbody` → one `Tr` per catalog row. Cells:
  - **Label** (`Td`): inline-editable `TextInput` (aria-label "Label"), monospace-ish key; error state uses `error` prop.
  - **Locale** (`Td`): inline-editable `TextInput` (defaults to `default`; multi-lingual-ready column, only `default` populated in v1).
  - **Value** (`Td`): growable `Textarea` (aria-label "Value"), raw markdown source, min ~2 rows, auto-grows with content.
- No pagination / virtualization — entire catalog loaded into one grid (D-06). Tens–low-hundreds of rows at v1.

**Row state affordances**
- **Pristine:** default surface (`neutral0`), no marker.
- **Dirty (edited existing) / New:** subtle `primary` indicator — a thin `primary600` left border or `primary100` row tint — signalling it will be included in the next Save. New rows keyed client-side before they receive a DB id.
- **Conflict (post-reject):** offending cell(s) get `danger600` border via the component `error` prop, plus inline `pi`-variant error copy beneath the cell. Whole save rejected atomically — no partial write (D-03).

## Interaction & State Contract

| State | Behavior |
|-------|----------|
| Loading | Strapi `<Loader>` / skeleton in the content area while the full catalog fetches. |
| Empty (no rows) | Empty-state heading + body + primary "Add row" affordance. |
| Filtered-empty | Namespace filter matched nothing → filtered-empty copy; filter control stays visible. |
| Editing | Inline cell edits mark the row dirty; edits are in-memory only until Save. |
| Add row | Appends a new dirty row inheriting the active namespace's key prefix (D-05); focus moves to the new Label cell's editable tail. |
| Save (success) | POSTs **only dirty + new rows** to `POST /ui-strings/bulk-upsert`; on 2xx, clears dirty flags, reconciles new rows with returned ids, shows success toast. |
| Save (conflict/reject) | On 4xx with per-row error detail, writes nothing; renders `danger` cell borders + inline row errors + the reject banner; dirty state preserved so the editor can fix and retry. |
| Load error | Full-area error message with a refresh path. |
| Accessibility | All editable cells carry aria-labels; focus rings use theme `primary600`; keyboard tab order flows Label → Locale → Value → next row; contrast + RTL inherited from Strapi theme. |
| Theming | Light/dark handled entirely by Strapi admin theme tokens — no per-mode overrides authored here. |
| Auth | Page sits behind Strapi admin authentication (SSO-backed via `src/admin/app.tsx`); no public/token surface. |
