<objective>
Add the client half of the Custom Copy Admin page: a custom Strapi admin page, mounted via the existing `src/admin` injection (D-01, not a standalone plugin), that lists the whole `ui-string` catalog as a three-column `Label · Locale · Value` spreadsheet-style grid with a client-side `namespace` filter, inline edit, add-row, and a single bulk Save that posts to the 38-01 endpoint (ADMN-01, ADMN-02).

Purpose: Replace the default content-manager as the intended authoring surface — a fast, load-all grid an organizer edits in bulk, saving all dirty + new rows in one atomic upsert.

Output: `src/admin/pages/CopyCatalog.tsx` (the page — the first `src/admin/pages/` file in the repo) plus a `register(app)`/`addMenuLink` hook added to `src/admin/app.tsx` (the first admin menu-link injection in the repo).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → this page | The page renders only inside the authenticated Strapi admin panel (SSO-backed via app.tsx); no public/token surface. |
| grid `value` cell → display | The value cell shows the stored markdown as RAW SOURCE in a textarea — it is never interpolated as HTML in the admin, so a crafted value cannot inject into the admin DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38-06 | Elevation | CopyCatalog page + menu link | high | mitigate | `addMenuLink` with `permissions: []` mounts the page inside the admin panel, which is already behind Strapi admin auth (app.tsx SSO). No new public route or token is introduced; Save uses the admin fetch client (admin-authed). |
| T-38-07 | Injection (XSS) | raw markdown in the value `Textarea` | low | accept | Value is displayed as raw source in a textarea, not rendered as HTML by the grid; downstream rendering is the Phase-36 escape-first sanitizer's job. Trust boundary documented. |
| T-38-08 | Info disclosure | client-side filter over full catalog | low | accept | The whole `default`-locale catalog is copy that authenticated admins are already authorized to read; loading it all client-side exposes nothing beyond the admin's existing content-manager access. |

No npm/pip/cargo installs in this plan (no external UI dependency added) → no supply-chain (T-38-SC) checkpoint required.
